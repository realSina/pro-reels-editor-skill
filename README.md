# PRO REELS EDITOR

An autonomous professional short-form video editing skill for Reels, Shorts, and TikTok.

## Overview

PRO REELS EDITOR is an editorial decision-making skill designed to approach short-form video editing like a professional human editor.

It focuses on:

- Storytelling
- Hook construction
- Retention
- Semantic editing
- Visual hierarchy
- Captions
- B-roll
- Framing
- Motion
- Sound design
- Music
- Color
- Brand consistency
- Editing consistency
- Quality control

The system prioritizes editorial judgment over unnecessary effects.

## Core Philosophy

Every edit must earn its place.

The system does not add effects simply because they are available.

It first asks:

> What does this moment need?

and then decides whether the answer is:

- A cut
- A framing change
- B-roll
- Caption emphasis
- Motion
- Sound design
- Music
- A transition
- Or no effect at all.
